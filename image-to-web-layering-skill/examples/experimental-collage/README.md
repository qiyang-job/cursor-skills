# Example: Experimental Collage

This folder is reserved for testing the skill with an experimental collage webpage image.

Suggested benchmark flow:

1. Put the source image here as input.png.
2. Run the analysis prompt from prompt.md.
3. Save the output as layering-report.md.
4. Extract assets based on the report.
5. Implement the page.
6. Score it using validation.md.

Target scores:
- Layer accuracy >= 4
- Content fidelity = 5
- Desktop visual fidelity >= 4
- Responsive usability >= 4
- Maintainability >= 4
- Interaction clarity >= 4
